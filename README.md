# CODE44 Business OS — скачивание

Официальные установщики: [GitHub Releases](https://github.com/Code44Team/Business-OS-Releases/releases).

Описание платформ и инструкции установки: [bos.code-44.com/download](https://bos.code-44.com/download/).

Этот репозиторий содержит установщики и сведения о выпусках. Исходный код продукта здесь не публикуется.

- Windows: EXE, x64.
- macOS: DMG для Apple Silicon и Intel; текущие сборки без подписи Developer ID.
- Linux: DEB и AppImage, x64.
- Android: APK, Android 9 и новее.
- iPhone и iPad: подготовка к публикации после подключения Apple Developer.

Business OS — продукт CODE44. Условия использования опубликованы на сайте продукта.
